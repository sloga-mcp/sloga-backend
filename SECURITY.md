# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

- **GitHub:** open the **Security** tab of this repository and choose
  **Report a vulnerability**. Only you and the maintainers can see the report.
- **Email:** support@sloga.gg with "Security" in the subject line.

Include what is affected (the web address, or the app, its version and your
device), steps to reproduce or a proof of concept, and what an attacker could do
with it. You can write in English or Portuguese.

We send a first reply within 72 hours, our assessment within 7 days, and updates
at least every 14 days until the fix is out. Please keep the details private
until then; we agree on a disclosure date with you, and we credit you if you want
credit.

The full policy, including what is in scope, the rules for testing and our safe
harbor for good-faith research: https://sloga.gg/legal/security.html

## This repository

This repository holds the Sloga server: the API, real-time events, file uploads,
link previews, voice integration and push notifications. Fixes are deployed to
the hosted service at app.sloga.gg.

## Upstream

Sloga is built on Stoat's open-source code (https://github.com/stoatchat). If a
problem also affects Stoat, we may share it privately with Stoat's maintainers so
their users get a fix too. We tell you before we do.
